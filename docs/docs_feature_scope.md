# Vellum 功能边界与实现归类

本文件依据当前产品目标和用户提供的编辑器界面参考，定义 Vellum 的功能归类。参考仅用于需求与交互层级分析；Vellum 的实现、文案和资源均独立编写，不复制参考产品源码或视觉资源。

| 功能 | Vellum 归类 | 实现位置 | 说明 |
|---|---|---|---|
| 代码样式方案、字体、字号 | 内置首选项 | `MtSettings`、`MtWindow` | 所有编辑任务的基础体验。 |
| 显示行号、当前行高亮、概览图 | 内置首选项 | `MtSettings`、`MtDocument` | 由每个文档视图同步应用。概览图使用 GtkSourceView 原生能力。 |
| 自动折行、右边界位置与显示状态 | 内置首选项 | `MtSettings`、`MtDocument` | 使用 GtkTextView/GtkSourceView 的原生折行与右边界接口。 |
| 自动缩进、真实 Tab 和显示列宽 | 内置首选项 | `MtSettings`、`MtDocument` | Tab 始终插入 U+0009；宽度只影响显示。 |
| 拼写检查 | 内置但可用性检测 | `MtWindow` | 仅在运行时存在系统拼写后端时启用；缺失时明确提示而不伪造检查结果。 |
| 会话/草稿恢复 | 内置首选项 | `MtSettings`、`MtDocument` | 现有草稿机制继续提供恢复开关。 |
| 主菜单、快捷键帮助 | 内置界面 | `MtWindow` | 提供 Vellum 已实现动作的可搜索快捷键清单。 |
| 项目侧边栏 | 可选扩展 | `project-sidebar` | 面向多文件项目，使用本地文件系统。 |
| 开发体验 | 可选扩展 | `dev-experience` | 仅执行用户明确配置的命令，不调用 shell。 |
| Vim 模式 | 可选扩展 | `vim-mode` | 会改变输入语义，默认不干扰普通编辑体验。 |
| AI 补全、链接测试、时间戳、统计 | 可选扩展 | 各自插件 | 各扩展均可启停。 |

## `.vut` 源码分发策略

所有 Vellum 内置扩展均提供来源可审阅的源码 `.vut` 包作为默认**可分发**形式。源码包针对本机 OS、CPU 架构和 ABI 构建模块，因而需要清单声明的 `make`、`cc`/`gcc` 等工具，以及与 Vellum 构建匹配的开发头文件和链接依赖。预编译模块仅可作为当前 AppImage 自身架构的运行时内置组件，不作为默认跨机器扩展分发载荷。

`.vut` 清单在构建前验证目标 OS、架构、ABI、插件 API、所需工具、构建参数和安全路径；构建过程在私有临时目录中通过参数数组直接启动 `make`、`cc` 或 `gcc`，不经 shell，不联网，也不提升权限。原生源码仍属于不受沙箱约束的代码，用户只能导入可信来源的扩展。

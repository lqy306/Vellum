# 参考布局提取记录

## 已核验的布局意图

用户要求将下列交互和信息层级转化为 Vellum 的独立 GTK4/Libadwaita 实现，不复制参考软件的源码、CSS、图标或图形资源。

| 区域 | 可复用的交互意图 | Vellum 独立实现方向 |
|---|---|---|
| 上下预览 | 深色上部编辑/内容区域和下部预览区域由一条清晰水平分割线隔开；分割位置可上下调整；中部把手为白色小框。 | Markdown Mode 使用 `GtkPaned` 的垂直方向，设最小高度、可拖动位置和自定义白色拖动把手 CSS。 |
| 标题栏 | 左侧文件/新建入口，中间突出文档名和较弱的状态/位置副标题，右侧信息、菜单与窗口控制。 | 保持 Vellum 自有 `AdwHeaderBar` 和动作体系，增加居中文档标题/副标题层级，不使用参考图标资源。 |
| 紧凑菜单 | 顶部三种外观选择；随后为缩放减小/显示百分比/放大；以下以分隔线组织文件、查找、视图和设置动作，并显示快捷键。 | 使用自定义 `GtkPopover` 内容而不是原来的纯 `GMenu`，实现三枚原创外观选择按钮、缩放按钮行和带快捷键标签的动作行。 |
| 文档属性面板 | 深色圆角分组中呈现名称、位置、文档类型、编码、换行符、缩进和统计；数值/控件右对齐。 | 新增可选 Document Inspector 扩展，以 AdwPreferences 行显示当前文档元数据、编辑设置和统计，避免将非核心工作流硬编码进主窗口。 |
| 主题卡片 | 大型语法着色预览加可选缩略卡片网格，选中状态明确。 | 保留并完善已有 Vellum 主题卡片选择器，只使用本机 GtkSourceView 安装的主题方案。 |

## 注意

新用户上传的紧凑菜单图片仅作为交互参考；根据用户明确要求，不再以文件查看方式读取该附件。

## 第二轮切片核验

标题栏右侧包含信息入口、菜单入口与窗口控制，并与居中的文档标题/状态保持清晰视觉区隔。文档属性面板的上部使用大圆角深色卡片：文件名、位置、文档类型、编码和换行符按行组织；属性名弱化，当前值更明亮并尽量右对齐。第二张卡片承载自动缩进、字符类型和缩进宽度调节，适合映射为 Vellum 的可选 Document Inspector 扩展。
